# Inkra handwriting subset

The default is now Xiaolai SC v3.120, supplied by `@inkra/react` with its OFL
license. The subset below remains available as the original font choice.
Additional theme fonts and their licenses are documented in [theme/README.md](theme/README.md).

`ui-hand-yozai.woff2` is the same local web subset used by the reference New Zealand site. It is based on Yozai Light v0.868 by lxgw and uses the internal family name `Trip Map Hand`.

- Source: `https://github.com/lxgw/yozai-font/releases/tag/v0.868`
- License: SIL Open Font License 1.1; see `Yozai-OFL.txt`.
- Coverage: 706 source characters selected for the original Adventure Map. Missing glyphs fall back to Xiaolai and then platform Kai fonts.
- The original font reserves the names `Yozai`, `YOz`, and `悠哉`; this subset uses a different internal family name.
